# Pacty Mascot Assets

This folder contains all the Pacty mascot images for different emotions and states.

## Image Requirements
- **Format**: PNG with transparent background
- **Size**: 1024x1024 pixels recommended
- **Style**: 3D rendered, consistent with brand

## Image Files Needed

Save your ChatGPT-generated images with these exact names:

1. `pacty_happy.png` - Default happy/friendly pose
2. `pacty_thinking.png` - Thoughtful, considering pose
3. `pacty_celebrating.png` - Excited celebration with confetti
4. `pacty_determined.png` - Confident, motivated pose
5. `pacty_tracking.png` - Analyzing data/charts
6. `pacty_splitting.png` - Sharing/splitting concept
7. `pacty_locking.png` - Secure/protection pose
8. `pacty_saving.png` - With coin stack
9. `pacty_goal_achieved.png` - Maximum celebration with trophy

## Where Each Image is Used

- **Happy**: Welcome messages, general positive feedback
- **Thinking**: Tips, suggestions, help prompts
- **Celebrating**: Small wins, milestones, completed contributions
- **Determined**: Goal setting, challenges, motivation
- **Tracking**: Dashboard, progress updates
- **Splitting**: Bill splitting features
- **Locking**: Security features, pact commitments
- **Saving**: Savings progress, deposits
- **Goal Achieved**: Major goals completed, achievements unlocked
